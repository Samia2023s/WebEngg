LearnPro Academy

Learn New Skills and Build Your Future**

LearnPro Academy is an educational website designed to introduce students to practical professional courses, including Web Development, Graphic Designing, and Digital Marketing. The project demonstrates a course information and enrollment website built using HTML, CSS, and basic JavaScript.

Features

- Homepage with academy introduction
- Three popular courses with fees and durations
- Course schedules and fee information
- Course enrollment form
- Contact information
- Navigation links
Technologies Used

- HTML
- CSS
- JavaScript (if implemented)

🚀 How to Run the Project

You can view the live project here:



Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Find the `index.html` file.
4. Double-click `index.html` to open the website in your browser.
5. Use the navigation menu to explore courses, schedules, enrollment, and contact information.

Note:For the best experience, use a modern browser such as Google Chrome or Mozilla Firefox.
